# Taller de impresión 3D

Herramientas para el flujo de diseño e impresión con Bambu Lab P1S.

| Herramienta | Qué hace |
|---|---|
| [`tools/bumpmesh`](tools/bumpmesh/README.md) | Aplica texturas de relieve de BumpMesh a STL desde la línea de comandos, con presets |
| [`tools/orientacion`](tools/orientacion/README.md) | Orientación de impresión de figuras (menos capas y soporte) y aletas de Support Fins en lote |
